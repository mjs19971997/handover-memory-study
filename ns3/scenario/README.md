# ns-3 scenario: Event A3 with a location memory of handover outcomes

Source of the scenario program (`a3-scenario.cc`, for ns-3.48 with the 5G-LENA `nr` module
v5.1, built natively on Windows), the scripts that install the tool chain and build the program
(`setup/`, `fix_srs.sh`, `build_scenario.sh`) and the script that starts the runs
(`run_sweep.py`).

The description of the files, the installation and the run commands is in
[`../README.md`](../README.md), section "Building and running the scenario"; the plan is
[`../PLAN_MEM.md`](../PLAN_MEM.md). The runs of the paper are in `../mem_urban/` and
`../mem_base/`.
